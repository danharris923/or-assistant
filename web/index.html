How this stays safe

  • Commands run as this user, not root.
  • With Ask first on, nothing runs and no file changes until you click Allow. Reading files and listing folders don't ask.
  • The page only works with the secret from its launcher; other websites and programs can't use it.
  • Your messages go straight to OpenRouter and the model provider, with no other server in between.
